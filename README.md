# Sayan Barman Portfolio

A handcrafted, scrapbook-style React + Vite portfolio for Sayan Barman.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```

## Add your resume

Place your real resume PDF here:

`public/Sayan-Barman-Resume.pdf`

## Replace links

In `src/App.jsx`, replace the `#` placeholders for GitHub, LinkedIn, Instagram and YouTube with your real URLs.
